# Content Parser — личный Telegram-бот для контента про нейросети и IT

Бот следит за Telegram-каналами и сайтами, которые ты ему укажешь, отбирает интересные темы и два раза в день присылает подборку. Под каждой темой есть кнопки:

- ✍️ **Уникализировать** — переписать пост своими словами, факты остаются те же;
- 📝 **Написать пост** — новый пост по теме на основе источников;
- 📖 **Подробнее** — подробная справка по теме лично для тебя;
- 👎 **Не интересно** — похожие темы бот будет оценивать ниже.

Под готовым постом: 🔁 ещё вариант, ✂️ короче, ➕ подробнее. Ещё можно **ответить (reply) на пост** своими словами: «убери эмодзи», «добавь вывод в конце», «сделай списком».

Можно и без подборки:
- написать «пост про Gemini 3»: бот найдёт свежие материалы в базе и напишет пост;
- переслать любой пост, прислать текст или ссылку на статью: бот уникализирует их или напишет пост по мотивам;
- переслать пост из нового канала: бот предложит добавить канал в источники.

## Как это устроено

```
Telegram-каналы ──(Telethon, от имени твоего аккаунта)──┐
Сайты ──(RSS, а если его нет — сама страница)───────────┤
                                                        ▼
                         каждые 30 мин: новые посты → убрать дубли → оценка 0–10 (дешёвая модель)
                                                        ▼
                    в 10:00 и 19:00: склеить одинаковые новости → топ-7 тем → тебе в личку
                                                        ▼
                         по кнопке: уникализация / пост / правки (сильная модель)
```

- Нейросеть подключена через [Polza.ai](https://polza.ai), у которого OpenAI-совместимый API. Модели настраиваются в `.env`.
- Всё хранится в одном файле `data/bot.db` (SQLite).
- Бот личный: отвечает только владельцу. Владельцем становится первый, кто нажмёт `/start`, или тот, чей ID указан в `OWNER_ID`.

## Что нужно подготовить

1. **Токен бота.** Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, придумай имя, и он пришлёт токен.
2. **api_id и api_hash.** Зайди на [my.telegram.org](https://my.telegram.org) → *API development tools* под тем аккаунтом, который будет читать каналы, и создай приложение (название любое). Подойдёт и основной аккаунт, и отдельный.
3. **Ключ Polza.ai**: личный кабинет → API-ключи. Пополни баланс.
4. **Python 3.11 или новее**: [python.org/downloads](https://www.python.org/downloads/). На Windows при установке поставь галочку **Add Python to PATH**.

## Установка и запуск

### Windows

1. Скачай проект (*Code → Download ZIP*) и распакуй в любую папку.
2. Дважды кликни **`run.bat`**. В первый раз он поставит зависимости и откроет файл `.env` в Блокноте.
3. Впиши в `.env` `BOT_TOKEN`, `POLZA_API_KEY`, `TG_API_ID`, `TG_API_HASH`, сохрани файл и снова запусти `run.bat`.
4. При первом запуске он спросит номер телефона аккаунта и код из Telegram (и пароль, если включена двухэтапная проверка). Это вход для чтения каналов, нужен один раз.
5. Открой своего бота в Telegram и нажми `/start`.

### macOS / Linux

```bash
cd путь/к/content-parser
```

```bash

```

Дальше всё как на Windows: заполни `.env`, снова запусти `./run.sh`, войди по коду и нажми `/start` в боте.

## Первые шаги в боте

```
/add @neurohub https://t.me/another_channel https://habr.com/ru/hubs/artificial_intelligence/
/topics            — опиши, какие темы интересны, а какие нет
/style             — пришли 3–5 своих постов, чтобы бот писал похоже
/digest            — получить подборку прямо сейчас
```

Все команды:

| Команда | Что делает |
|---|---|
| `/add …` | добавить каналы и сайты, можно несколько через пробел |
| `/sources` | список источников, удаление кнопкой |
| `/digest` | собрать свежее и прислать подборку сейчас |
| `/topics` | показать или поменять описание интересов |
| `/style` | образец твоих постов; `/style сброс` — убрать |
| `/time 9:00 18:30` | время подборок |
| `/size 5` | сколько тем в подборке |
| `/threshold 6` | минимальная оценка темы (0–10): ниже — шире подборка |
| `/settings` | текущие настройки |

**Закрытые каналы.** Подпишись на канал тем аккаунтом, который читает каналы, и перешли боту любой пост оттуда. Появится кнопка «Добавить канал в источники».

## Пробный прогон без Telegram

Проверить, как бот читает сайты и что попадёт в подборку, можно прямо в консоли:

```bash
python -m bot.dry_run https://habr.com/ru/rss/hubs/artificial_intelligence/articles/
```

```bash
python -m bot.dry_run --write https://habr.com/ru/rss/hubs/artificial_intelligence/articles/
```

С `--write` бот ещё и напишет пост по первой теме. Без `POLZA_API_KEY` (или с `--fake`) вместо нейросети работает заглушка.

## Сколько стоит нейросеть

Примерно, по ценам каталога Polza на конец октября 2026:
- **Отбор** (`openai/gpt-4.1-mini`): около 300–400 ₽ в месяц, если в источниках выходит ~300 постов в день. Меньше источников — дешевле.
- **Один пост или уникализация** (`openai/gpt-5.4`): примерно 1–3 ₽.

Модели меняются в `.env` (`LLM_MODEL_FAST`, `LLM_MODEL_SMART`), список — на [polza.ai/models](https://polza.ai/models). ID пишется вместе с провайдером, например `openai/gpt-5-mini`.

## Если что-то не так

- **«Не удалось связаться с Telegram».** Проверь интернет. Если Telegram у провайдера тормозит, впиши SOCKS5-прокси в `TG_PROXY`.
- **«Polza не принял ключ» / «закончились деньги» / «модель не найдена».** Проверь `POLZA_API_KEY`, баланс и ID моделей в `.env`.
- **Сайт не добавляется («не нашёл ни RSS, ни ссылок на статьи»).** Сайт, скорее всего, рисуется JavaScript'ом. Поищи у него RSS (часто это `/feed` или `/rss`) и добавь ссылку на RSS напрямую.
- **Подборки пустые.** Снизь порог: `/threshold 5`, или расширь интересы через `/topics`.
- **В подборке много мусора.** Подними порог (`/threshold 7`), жми 👎 на неинтересном и уточни `/topics`.

## Безопасность

- Файл `data/userbot.session` даёт доступ к Telegram-аккаунту. Не отправляй его никому и не выкладывай в интернет. `.env` и `data/` уже в `.gitignore`.
- Бот только читает каналы: ничего не публикует и ни на что не подписывается сам.
- Не добавляй сотни каналов и не ставь сбор чаще раза в 10–15 минут, чтобы Telegram не ограничил аккаунт.

Структура:

```
bot/
  __main__.py        запуск: бот + чтение каналов + расписание
  login.py           одноразовый вход в аккаунт
  config.py          настройки из .env
  db.py              SQLite
  collectors/        telegram.py (Telethon), web.py (RSS / HTML)
  llm.py, prompts.py нейросеть и тексты промптов — правь prompts.py, чтобы поменять тон
  pipeline.py        сбор → дедуп → оценка → подборка → генерация
  handlers/          команды, кнопки, свободный режим
  scheduler.py       сбор каждые N минут и подборки по времени
```
